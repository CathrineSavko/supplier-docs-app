# Документы поставщиков

Локальное приложение для шести сценариев подготовки документов поставщиков.

## Запуск

Дважды щёлкните `Start_Supplier_Docs.cmd` (или `Запустить приложение.cmd`). Через несколько секунд браузер откроет адрес `http://127.0.0.1:3213`.
Не закрывайте свёрнутое окно `Supplier Docs Server`: это работающий локальный сервер. Закрытие остановит приложение.

## Где хранятся файлы

- Постоянные шаблоны: `app/data/templates/`.
- Файлы конкретных запусков: `app/data/jobs/`.

В первой версии готовы интерфейс, локальное сохранение шаблонов и приём файлов для всех шести сценариев. Задача №6, «Инвойсы на оплату», уже обрабатывает `.xlsx` и выдаёт готовый файл в браузере. Остальные обработчики Excel и Word подключаются отдельно и проверяются на исходных примерах, чтобы не нарушить визуальное оформление документов.
